## Context

This is a golf game made for the Mini Jam 202 which is hosted on itch.io. It was my first game made in GameMaker Studio.

## What I Learned

For this game, I wanted to try out the GameMaker game engine. I experimented with top down physics and a clean vector artsyle.

## What Could be Improved on

- I tried making a soundtrack again, which I struggled with. I feel the music is too rushed, so in future I could spend more time on this.
- More levels.
- More powerups. I implemented the idea of powerups early, but because of what appears to be a restriction with GameMaker, I couldn't reuse the transition screen, so each new powerup needed a separate one.

## Conclusion

Overall, I liked using GameMaker, however, the lack of UI system and predefined behaviours - akin to what you get in Construct, made the development much slower than what I'm used to.
